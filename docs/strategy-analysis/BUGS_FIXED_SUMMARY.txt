BUG #1: shouldPrioritizeDefense() = FALSE at Mutual Contact + 60% HP
─────────────────────────────────────────────────────────────────
  PROBLEM: Defense chip never activated when both leeks could shoot + player wounded
  ROOT CAUSE: Binary logic - only checks asymmetry (enemy shoots, I don't)
  SCENARIO: Kassbi vs Kaine111 Tour 6: distance=1, HP=39%, both MG
  OLD RESULT: shouldDefense = FALSE ❌
  FIX: Added mutual contact danger check (enemyShoot && iCanShoot && HP<=60%)
  NEW RESULT: shouldDefense = TRUE ✅
  IMPACT: Defense chips now activate in mutual contact situations

BUG #2: shouldHeal() = FALSE at Tours 4-5 (Lazy Healing)
──────────────────────────────────────────────────────
  PROBLEM: Healing delayed too long due to 25% damage threshold
  ROOT CAUSE: Threshold-based only, ignores distance/threat context
  SCENARIO: Kassbi vs Kaine111 Tours 4-5: distance=5-2, HP=92%→71%, lifeLost=7.9%→22.4%
  OLD RESULT: NO HEAL (22.4% < 25%) ❌
  FIX: New method shouldHealWithThreat() - heal if distance≤10 && HP≤70% && damage≥10%
  NEW RESULT: HEAL at Tour 5 ✅ (1 turn earlier!)
  IMPACT: Reactive healing when enemy nearby + moderate damage

BUG #3: shouldHide() = FALSE at Tours 4-5 (Retreat Too Late)
───────────────────────────────────────────────────────────
  PROBLEM: Retraite only when HP critically low, missing preemptive cases
  ROOT CAUSE: AND condition too strict - needs both tooClose AND wounded(45%)
  SCENARIO: Kassbi vs Kaine111 Tour 5: distance=2, HP=71%, isWounded=false
  OLD RESULT: NO HIDE ❌
  FIX: Added preemptive condition - hide if distance≤2 && HP≤70%
  NEW RESULT: HIDE at Tour 5 ✅ (1 turn earlier!)
  IMPACT: Anticipatory retreat before crisis
